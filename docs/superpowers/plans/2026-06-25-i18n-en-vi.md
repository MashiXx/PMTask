# EN/VI Internationalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add full English/Vietnamese language support across the entire PMTask UI, switchable from the Settings (Profile) page, defaulting to English.

**Architecture:** A lightweight custom i18n layer (no i18n library). Locale strings live in `src/locales/{en,vi}.json`. A core module `src/config/i18n.js` exposes a `t(key, lang, vars)` lookup with English fallback and `{var}` interpolation. Express middleware resolves the active language (`req.user.language` → cookie `pmtask-lang` → `'en'`) and exposes `res.locals.lang` / `res.locals.t` / `req.t` to views and controllers. Client-side strings are injected as `window.__I18N__` and read via a small `window.t()` in `/js/i18n.js`. Language preference persists in `User.language` (DB) and a cookie.

**Tech Stack:** Express 5, EJS, Prisma (MySQL), vanilla JS. New: `cookie-parser`. Tests via Node built-in `node:test`.

**Key conventions (used by every extraction task):**
- Key naming: `area.name`, flat keys. Areas: `sidebar.*`, `topbar.*`, `auth.*`, `profile.*`, `dashboard.*`, `projects.*`, `documents.*`, `task.*`, `mindmap.*`, `admin.*`, `flash.*`, `common.*`, and `js.*` (client-side only).
- Server EJS: replace hardcoded text with `<%= t('area.key') %>`. For attributes (e.g. `title=`, `placeholder=`) use `<%= t(...) %>` inside the quotes.
- `title` passed to `head.ejs`: `include('partials/head', { title: t('area.key') })`.
- Controllers: `req.flash('error', req.t('flash.key'))`.
- Client JS: replace hardcoded text with `t('js.key')` (global `window.t`).
- Every new key MUST be added to BOTH `en.json` and `vi.json` in the same task.

- [ ] **Step 3: Create the core module**

Create `src/config/i18n.js`:
```js
const en = require('../locales/en.json');
const vi = require('../locales/vi.json');

const LOCALES = { en, vi };
const SUPPORTED = ['en', 'vi'];
const LABELS = { en: 'English', vi: 'Tiếng Việt' };

function normalizeLang(lang) {
  return SUPPORTED.includes(lang) ? lang : 'en';
}

function interpolate(str, vars) {
  if (!vars) return str;
  return str.replace(/\{(\w+)\}/g, (m, k) => (k in vars ? String(vars[k]) : m));
}

function t(key, lang, vars) {
  const l = normalizeLang(lang);
  let str = LOCALES[l][key];
  if (str === undefined) str = LOCALES.en[key];
  if (str === undefined) {
    if (process.env.NODE_ENV !== 'production') console.warn(`[i18n] missing key: ${key}`);
    return key;
  }
  return interpolate(str, vars);
}

// Only js.* keys, with English fallback, for embedding in the page for client JS.
function clientDict(lang) {
  const l = normalizeLang(lang);
  const out = {};
  for (const k of Object.keys(LOCALES.en)) {
    if (k.startsWith('js.')) out[k] = LOCALES[l][k] !== undefined ? LOCALES[l][k] : LOCALES.en[k];
  }
  return out;
}

module.exports = { t, normalizeLang, clientDict, SUPPORTED, LABELS };
```

```js
app.use((req, res, next) => {
  res.locals.currentUser = req.user || null;
  // Only two themes remain; map any retired value (system / azure / vintage) onto them.
  const savedTheme = req.user ? req.user.theme : 'light';
  res.locals.userTheme = savedTheme === 'dark' ? 'dark' : 'light';

  // Language: user preference -> cookie -> default 'en'

  else if (req.cookies && req.cookies['pmtask-lang']) lang = req.cookies['pmtask-lang'];

  res.locals.clientI18n = JSON.stringify({ lang, dict: clientDict(lang) }).replace(/</g, '\\u003c');
  next();
});
```

```js
exports.updateLanguage = async (req, res) => {
  try {
    const { language } = req.body;
    if (!SUPPORTED.includes(language)) {
      return res.status(400).json({ error: 'Invalid language' });
    }
    await prisma.user.update({
      where: { id: req.user.id },
      data: { language },
    });
    res.cookie('pmtask-lang', language, {
      maxAge: 365 * 24 * 60 * 60 * 1000,
      sameSite: 'lax',
      httpOnly: true,
    });
    res.json({ success: true });
  } catch (err) {
    console.error(err);
    res.status(500).json({ error: 'Failed to update language' });
  }
};
```

## Task 6: Client i18n.js (window.t + setLanguage)

**Files:**
- Create: `src/public/js/i18n.js`

- [ ] **Step 1: Create the client helper**

Create `src/public/js/i18n.js`:
```js
(function () {
  var data = window.__I18N__ || { lang: 'en', dict: {} };

  window.t = function (key, vars) {
    var str = data.dict[key];
    if (str === undefined) str = key;
    if (vars) {
      str = str.replace(/\{(\w+)\}/g, function (m, k) {
        return Object.prototype.hasOwnProperty.call(vars, k) ? vars[k] : m;
      });
    }
    return str;
  };

  window.currentLang = data.lang;

  window.setLanguage = function (lang) {
    fetch('/profile/language', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ language: lang }),
    })
      .then(function (r) { if (r.ok) location.reload(); })
      .catch(function () {});
  };
})();
```
